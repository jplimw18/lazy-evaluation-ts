# Lazy Evaluation com TypeScript

## Contexto

Este projeto se trata de um experimento e aprofundamento no etendimento de *call-by-need* efetuado por linguagens tidas como funcionais e não reflete uma aplicação real

## Objetivo

O objetivo é conseguir entender de forma mais elementar para efetuar a aplicação destes conceitos para uma lib próprio (também sendo feita a propósito de estudos) com c++ e abrir espaço para introdução de métodos formais

> [!Importane]
> Este projeto está em andamento e se trata de uma pesquisa e estudo para abrir portas para outras ideias de interesse
